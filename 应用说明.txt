晨曦短剧梦工坊 - 应用说明 (v2.7.0)

【2.7.0 版本更新】
1. 启动生成自动合并成片 (VAD+ASR 字幕烧录):
- 短剧工坊点击"启动生成"后, 全部分镜视频生成完成会自动执行:
  合并 → VAD 语音切分 (ffmpeg silencedetect) → sherpa-onnx SenseVoice 逐段识别
  → 噪声过滤 → 超 4 秒长段按时间硬切 → 烧录中文字幕 (底部居中微软雅黑)
- 输出 <剧名>_完整版.mp4 到分镜目录, 原始分镜片段全部保留不删除
2. 分镜时长按模型自动适配:
- 选择模型后默认分镜时长自动取该模型支持的最大值:
  * 火山方舟 Seedance/豆包 → 60s (档位 4/8/12/16/20/24/30/60)
  * agnes-video-2.5-flash 等 v2.5 系 → 12s (档位 4/8/12)
  * agnes-video-2.0 系 → 5s (固定)
- 默认分镜时长支持手动输入任意 1~60 秒
3. 便携版离线部署:
- 桌面版内置 Python 3.11 运行时 + ffmpeg + SenseVoice ASR 模型
- 新设备开箱即用, 无需安装任何依赖

【版本更新提醒】

- 用户自主选择是否升级; 不升级不影响任何功能正常使用

【v2.6 功能回顾】

📚 剧本存档（短剧工坊底部）
工作流: 第一季做完 → 保存存档 → 清除工坊开新剧 → 以后导入存档 → 第二季人物一模一样地延续。
- 💾 保存当前剧本存档: 保存剧集设定、全部人物设定卡、全部集数历史与悬念、总集数等进度
- 📤 启用续季: 导入后人物卡逐字继承、主提示词保留、季数+1 集数从第 1 集重新开始
- 导出 JSON 备份 / 跨设备迁移 / 删除管理

【时长与合并】
1. 分镜时长:
- agnes-video-2.0 系: 固定输出 5 秒 4:3, 完全忽略时长与比例参数 (提交时明确警示)
- agnes-video-2.5-flash: 支持 4/8/12 秒档位与 9:16 竖屏
- OpenAI 兼容平台时长档位自动吸附: ≤5s 原样, 6~9s → 8s, ≥10s → 12s
- 视频保存后自动探测实际时长, 与设定不符时作品库显示 ⚠️
2. 重复生成治理:
- 相同内容 (提示词+时长+参考图) 且同标题下已有完成视频的, 直接复用不重复扣配额
- "任务扫描"无进行中任务也能执行查重, 重复完成作品可批量清理
3. 视频合并:
- 自动合并与"合并已选作品目录"同时支持桌面版与服务器模式
- "📦 手动合并视频": 多选本地视频, 可调顺序/剔除/自定义成片名, 合并+烧录字幕
- 对同一集重复合并时, 旧 _完整版.mp4 不会再次吞入新合并

【核心能力】
- 多平台兼容: 火山方舟(Seedance) / OpenAI兼容 / 完全自定义JSON 三种预设+自动识别
- 通用本地代理: 任何平台都能绕过浏览器 CORS 限制
- 批量并行: 多场景同时提交、并发轮询，互不影响
- 限流自适应: 提交遇 429 全局串行排队+统一冷却退避, 已提交任务不受影响
- 一键重试: 失败/未知任务在作品库点"重试"即可，无需重新填写
- 轮询终态保护: 连续出错/查询不到/超30分钟标记"未知"，不永久卡"排队中"
- 自动保存: 生成完成自动下载视频到 output/video/<标题>/ 目录
- 短剧工坊: 剧本AI延伸剧情, 人物面孔/声音全剧锁定, 一键生成下一集, 全剧挂机到完结

【短剧工坊用法】
1. 模型设置 → 剧本AI: 填一个文本模型ID (如 doubao-pro-32k / gpt-4o-mini / deepseek-chat)，
   默认复用视频平台的端点和密钥
2. 短剧工坊页: 填剧集名称/类型/世界观主线，选择分辨率和画面比例
   (竖屏短剧选 9:16，剧本AI会把比例写进每个分镜)
3. 点"AI生成人物设定卡": 每个角色的面孔/声音/服装描述会全剧锁定
4. 点"AI写剧本"或"批量添加情景"(每行一个情景)
5. 点"用当前分镜启动生成": 批量生成全部分镜视频, 完成后自动合并+烧录中文字幕
6. 点"一键生成全剧": 挂机循环写剧本→出片→合并, 直到总集数完结

【免费平台限流(429)说明】
- 所有提交请求全局串行排队，同一时刻只发一个
- 任一请求触发 429，所有任务统一冷却退避 (20s→40s→60s→90s→120s 逐次加倍)
- 免费套餐下一键生成下一集 (4分镜) 自动排队几分钟属正常现象

【使用方法】
1. 双击 start-server.bat (需 Node.js 18+，首次先 npm install)
   或使用桌面版: 双击 晨曦短剧梦工坊.exe (便携版免安装)
2. 打开 http://localhost:3000
3. 模型设置页: 选平台预设 → 填端点和密钥 → 保存设置
4. 批量生成页: 填标题和提示词 → 开始批量生成

【桌面版打包】
cd <项目目录>
npm run desktop:build
产物在 desktop-dist/: 便携版 exe + 安装版 exe
(打包前需本地准备 resources/ 目录: Python 运行时 + ffmpeg + ASR 模型)
